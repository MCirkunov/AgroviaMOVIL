# AgroVIA móvil

Versión Dash adaptable a teléfonos, sin marco visual de dispositivo.

## Publicar como app separada en Render

1. Crea un repositorio nuevo en GitHub.
2. Sube el contenido de esta carpeta a la raíz del repositorio, conservando `assets/` y `dominio/`.
3. En Render, crea un Blueprint desde ese repositorio y acepta la configuración de `render.yaml`.
4. Comparte la URL HTTPS generada por Render. Ábrela desde el teléfono para usar la interfaz a pantalla completa.

El documento `AgroVIA_Terminos_y_Condiciones.docx` puede quedarse en la raíz; la app lo busca allí. La demo usa datos de ejemplo y no sincroniza cambios entre usuarios.
